# أوراق تفاعلية

منصة عربية لإنشاء أوراق عمل تفاعلية من ملفات PDF، إرسالها للطلاب، وتصحيحها تلقائياً
مع رصد الدرجات — على غرار liveworksheets.com لكن بواجهة عربية بالكامل.

## المزايا

- تسجيل حسابات معلم وطالب، وربط الطلاب بصف المعلم عبر رمز صف فريد.
- رفع ملف PDF لورقة العمل يتم تحويله تلقائياً إلى صفحات صور.
- محرر بالسحب والإفلات لوضع عناصر تفاعلية فوق صفحات الورقة: فراغات نصية،
  اختيار من متعدد، صح/خطأ، ومربعات اختيار، مع تحديد الإجابة الصحيحة ودرجة كل سؤال.
- نشر الورقة وتعيينها لطلاب محددين من صف المعلم.
- الطالب يحل الورقة إلكترونياً فوق صورة الصفحة الأصلية ويحصل على تصحيح تلقائي
  فوري مع إظهار الإجابة الصحيحة عند الخطأ.
- سجل درجات لكل ورقة عمل يعرض حالة كل طالب ودرجته وتاريخ التسليم.

## المتطلبات

- Node.js 20+
- أداة `pdftoppm` من حزمة `poppler-utils` مثبّتة على الخادم (تُستخدم لتحويل صفحات
  PDF إلى صور PNG). على Debian/Ubuntu:

  ```bash
  apt-get install -y poppler-utils
  ```

## الإعداد المحلي

```bash
npm install
cp .env.example .env   # عدّل JWT_SECRET قبل الإنتاج
npx prisma migrate deploy
npm run dev
```

يفتح الموقع على http://localhost:3000

## البنية التقنية

- **Next.js (App Router) + TypeScript + Tailwind CSS** للواجهة والـ API.
- **SQLite عبر Prisma** لقاعدة البيانات (ملف واحد، بدون خدمة خارجية).
- **جلسات JWT في كوكيز httpOnly** للمصادقة (بدون خدمة خارجية).
- **pdftoppm (poppler-utils)** لتحويل صفحات PDF إلى صور PNG تُحفظ في
  `public/uploads/worksheets/<id>/` ليتم عرضها مباشرة.
- ملفات PDF الأصلية تُحفظ في `storage/pdfs/` (غير متاحة للعامة).

## ملاحظة على النشر

نظراً لاعتماد المعالجة على أداة `pdftoppm` كسطر أوامر، يجب نشر الموقع على بيئة
تسمح بتشغيل عمليات نظام (مثل خادم Node.js تقليدي أو حاوية Docker) وليس على
منصات serverless لا تدعم تثبيت حزم نظام مثل poppler-utils.
